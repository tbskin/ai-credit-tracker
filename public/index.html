BROWSER CONNECTION

Read the balance you see.

For wallets without a balance API, the extension reads the number you select on your billing page. Login cookies stay in Chrome.

  1. Open chrome://extensions, turn on Developer mode, and choose Load unpacked. Select this project’s extension folder.
  2. Click Get pairing code below, then paste it into the extension popup.
  3. Connect a provider with the Browser method. Open its billing page, then choose Select balance in the extension.
Valid for 5 minutes. Pairing again replaces the previous connection.

Refresh opens billing pages in background tabs and closes only the tabs it creates. Chrome and this app must be running. If a page changes or your login expires, you’ll see a reconnect message.
